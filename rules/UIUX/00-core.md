# UIUX 핵심 강제 규칙 (BGT)

> 정본: `docs/pmx-uiux-audit/rules/` (체크리스트 47항목 · 표준가이드 182 세부규칙 · 가이드 목업 65장 · **룰북 발췌 2종**). 상세 규칙은 `.claude/rules/UIUX/01~04`.
> **조회조건과 팝업은 `rules/rulebook/` 이 우선한다**(182 세부규칙은 2026-07 추출본이라 그 뒤 개정이 빠져 있다) — 구현 규칙은 `develop/b-feature/b-23`(조회조건)·`develop/a-archetype/a-03` §5~6(팝업).
> 대상: `bgt-fe` 화면/컴포넌트 구현·수정 전부. 공통 UI=`@amxis/design-system`, 그리드=IBSheet 로 구현하되 아래를 지킨다. 디자인시스템이 동등 토큰을 주면 임의 값 하드코딩 금지.

## A. 게이트 (공통필수 16항목 — 하나라도 어기면 화면 FAIL)

1. **화면 제목·담당자** — 최상단에 화면 타이틀(= 선택 메뉴명과 **일치**) + 업무담당자 배지. 타이틀 말줄임 금지. (#1)
2. **업무 흐름** — 정보·기능을 **상→하, 좌→우** 순서로 배치. 역행 금지. (#2)
3. **화면 패턴** — 업무 성격에 맞는 Page UI Pattern 9타입 중 선택. → `03` §1 (#3)
4. **상세 제공 방식** — In page / Move page / **Dialog**(셀·항목 단위) 중 적절히 선택. → `03` §3 (#4)
5. **해상도** — 기준 `1920×1080`, 최저 `1194×768`. 불필요한 가로 스크롤 금지, Header/Left 고정, 1424px 이하 Left 접힘. → `01` §5 (#5)
6. **Frame** — Header/Left/Contents/MDI Tab 의 고정·스크롤 정책 준수. → `02` §1 (#6)
7. **버튼 스타일** — 중요도에 따라 Primary/Normal × Contained/Outlined/Unfilled 구분. 조회=Normal Contained, 저장=Primary Contained, 취소·임시저장=Normal Outlined. → `04` (#14)
8. **Grid 패턴** — 목록/편집/마스터-디테일/Tree 중 목적에 맞게. → `03` §4~9 (#19)
9. **컬럼 정렬** — 코드·날짜·성명=중앙 / 서술형=좌측(+말줄임) / **숫자=우측 + 천단위 콤마**. 링크=파란색+밑줄. (#20)
10. **필수·유효성** — 필수는 라벨 앞 **빨간 `*`**, Validation 은 **입력란 컬러 + 하단 Helper Text(1줄)**. 단 **조회조건은 기본이 선택 입력이라 `*` 없는 게 정상**(없다고 위반 아님). (#28)
11. **중요정보 마스킹** — 비밀번호·주민번호·계좌번호는 입력·출력 **모두 `*`**. (#32)
12. **Confirm** — 저장/삭제 등 되돌리기 어려운 작업 전 **컨펌 Dialog**("삭제하시겠습니까?"). (#33)
13. **Toast** — 완료/실패는 **Toast, 화면 중앙 하단**("저장되었습니다."). 하단에서 `60px` 위, 2줄 이내, 4초 자동 소멸. (#34)
14. **Empty State** — 0건·권한없음·오류·선택 전에 **완전 공백/에러 노출 금지**. Page/Grid/with Suggestion 3종 중 선택하고, Grid형은 **검색영역·컬럼헤더를 남긴다**. → `03` §11 (#38)
15. **Dialogue 구조** — Title / Function / Contents / Button Area + Dimmed. Alert=확인 1개, Confirm=2개, 중요 버튼 우측. 화면 팝업의 버튼 구성·메시지 규약은 `develop/a-archetype/a-03` §5~6(D1~D14). → `02` §3 (#39)
16. **명도대비** — 배경:텍스트 **4.5:1** 이상(모바일 3:1). (#45)

## B. 정량 규칙 (자주 어김)

- **색상** — Primary `#037AF2`. 팔레트(→ `01`) 밖의 색 신규 정의 금지. 한 화면 **3~5개 이내**.
- **세로 간격** — 모듈 내부 `4px` / 조회조건 행간 `8px` / 모듈-모듈·폼아이템 행간 `12px`.
- **가로 간격** — 모듈 간 `24px` / 입력요소 간 `4px` / 라벨-입력폼 `8px` / 체크박스·라디오 간 `12px`.
- **콘텐츠 레이아웃** — 12 컬럼, gutter `24px`. 분할은 `6:6` / `2:10` / `4:4:4` / `8:4` 만.
- **조회조건** — 전 필드 `labelAlign="left"` + **열 단위** 동일 `labelMinWidth`(화면 전체 단일값 아님). 조건을 전폭 묶음 `<Grid container item xs={12}>` 로 감싸지 않고 한 행 `xs` 합 ≤ 12. 유형별 열수 = 콤보·단일날짜·라디오 2 / 키워드 2~3 / 기간·멀티칩·코드+명 팝업 3 / 프로젝트 4. 버튼영역은 DS 가 그린다(자리 예약 금지). 다중선택은 태그형 `DropdownField multiple`(체크박스 바둑판 금지).
- **타이포** — **Pretendard**, PC 본문 `13~14px`, 한 화면 **3~5종 이내**. 기본 `Regular`, 강조만 `Bold`. Letter spacing `-3%`.
- **포맷** — 날짜 `YYYY.MM.DD`, 시간 24시간제 `HH:mm`.
- **그리드 셀 상태** — 편집가능 = 흰 배경/파란 텍스트, Readonly = 회색 배경/검은 텍스트.
- **편집 그리드 행 상태** — 상태컬럼은 **체크박스 다음 두 번째 컬럼**. `[추가됨]`=연한 초록 배경 / `[삭제됨]`=연한 적·주황 배경 + **취소선**(즉시 사라지지 않음) / `[변경됨]`. 저장 시 flagCd C/U/D 매핑.
- **버튼 배치** — 모듈 버튼은 **Normal·Outlined·Small**, 대상 모듈 **우측 상단**. 순서 **신규/행추가 > 삭제/행삭제 > 복사 > 위 > 아래 > 업로드 > 다운로드 > 새로고침**, 표준 외 기능버튼은 그 **좌측**, 저장·확정은 **최우측**(임시저장은 그 좌측). 조회영역 순서 **초기화 > 조회 > 기능 > 저장**(조회군과 저장군은 구분선 분리).
- **아이콘** — 기준 `24×24px`, 최소 `8px`, **2의 배수** 스케일, 선 두께 `1.5px`.

## C. MUST NOT

- 팔레트/스페이싱/타이포 스케일 밖의 **임의 값 하드코딩**.
- Page Title·Sub Title **말줄임(...) 처리**.
- 옵션 **5개 이하인데 Dropdown** 사용 → Radio Button. 다중선택을 **체크박스 바둑판**으로 배열.
- 조회조건을 **전폭 묶음(`xs={12}`)** 으로 감싸기 · 버튼 자리를 **빈 칸으로 예약**하기.
- **Tab 8개 이상** 또는 한 줄 초과 배치, Tab in Tab 남용, 3단 이상 중첩.
- 그리드 **가로 스크롤 남발**·불필요한 전체화면 가로 스크롤 유발.
- Empty State 자리에 **빈 화면·에러 스택** 노출.
