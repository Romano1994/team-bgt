# 01. Foundation Tokens — 색상·타이포·스페이싱·아이콘·해상도

> 정본: `docs/pmx-uiux-audit/rules/uiux-standard-rules.md`(182 세부규칙) + `docs/PMX-UI표준가이드_통합정리.md` p.7~9·p.21~22(색상·아이콘·스페이싱·타이포는 audit 추출 범위 밖이라 통합정리가 유일 근거).

### 버튼 색상 매핑 (p.66 — 판정 대상)
- **조회** = Normal Contained(짙은 남색·차콜) / **저장** = Primary Contained(파란색) / **취소·임시저장** = Normal Outlined / **새로고침** = 원형 아이콘 전용 버튼.
- 특수 버튼: **AI** = 민트 Outlined + 스파클 아이콘 / **카카오톡 발송** = 노랑 Contained + 말풍선 아이콘.

### 접근성 명암비 (MUST)
- 웹: 배경:텍스트 명암비 **4.5:1** 이상 (한국형 웹 접근성 2.1). 모바일 **3:1** 이상.
- 텍스트 24px↑는 완화 가능. 로고·장식 텍스트·focus 상태는 예외.
- *(명암비 부적합 예시의 구체 수치·일부 HEX는 추출 손상 — 원본 확인)*

## 2. Typography (p.22)

- **기본 서체: Pretendard.** 국문 외 다국어는 OS 기본 서체(Windows 맑은고딕/Segoe UI/MS YaHei, macOS Apple SD 산돌고딕 Neo/SF Pro/SF Pro SC, Android Noto Sans CJK KR/Roboto/Noto Sans CJK CN, iOS Apple SD 산돌고딕 Neo/SF Pro/PingFang SC).
- **크기**: PC 본문 `13~14px`, 모바일 `16px`. 서브텍스트·캡션은 1~2단위 축소, 타이틀·강조는 2 또는 4의 배수 확대. **한 화면 3~5종 이내.**
- **Weight**: 기본 `Regular`, 강조·가독성 필요 시 `Bold`.
- **Line Height**: WCAG 2.1 고려, 표준 최소치 이상.
- **Letter Spacing**: 기본 `-3%`, 요건 따라 조절.
- 공통 요소(버튼/타이틀/입력폼)는 size·color·weight 통일.

## 4. Icon (p.9)

- 기준 사이즈 **`24×24px`**, Corner Radius `3px`, Keyline 패딩 `2px`.
- 선 두께 기본 **`1.5px` Lined**, 작은 사이즈는 Solid 허용.
- 사이즈 스케일(2의 배수): `24 · 22 · 20 · 18 · 16 · 12 · 8`, **최소 `8px`**.
- 메타포 2개 초과 금지(단순 형태). 아이콘 컬러는 텍스트 컬러 체계를 따른다.
- 32px 이내 소형에 사용 권장. 큰 그래픽은 별도 디자인.

## 5. 해상도 / 반응 정책 (p.4~6)

### 5.1 기준값
| 구분 | 값 |
| --- | --- |
| 기준 PC 해상도 | `1920 × 1080` |
| 기준해상도 내 Screen 가용범위 | `1920 × 942`(브라우저 프레임 92px + 작업표시줄 46px 제외, Edge 140 기준) |
| 최저 지원 해상도 | `1194 × 768` (iPad 11" Pro 가로스크롤 미발생 기준) |
| 최대 | `1920px` 초과 시 **유동폭** |

- 기준 브라우저 Edge(+ Chrome/Firefox/Safari, 모바일 Chrome/Samsung/Safari). 다국어: 국문·영문·중문·베트남어.

### 5.2 영역별 스크롤 정책
- **Header Area**: 좌우 유동 확대/축소, **내부 가로·세로 스크롤 금지**, 상단 고정.
- **Left Area**: 너비 **해상도 무관 고정값**, 내부 세로 스크롤만 허용.
- **Content Area**: 브라우저 너비에 따라 유동 확대/축소.
- **Data Grid**: 폭 축소 시 **영역 내부** 가로·세로 스크롤 허용(예외).

### 5.3 구간별 규칙
| 구간 | 범위 | 규칙 |
| --- | --- | --- |
| ① 최저~FHD | 1194×834 ~ 1920×1080 | 컨텐츠 유동. iPad(1194×834)에서 숨겨진 UI는 대체 UI 또는 스크롤 필수. **1424px 이하에서 Left Area 기본 접힘.** 우선순위 높은 정보는 스크롤 없이 노출 |
| ② 기준 초과 | >1920px | 유동폭으로 UI 확대 배치 |
| ③ 최저 미만 | <1194px | Content 최소폭 `1194px` 고정, **Content Area 전체 가로 스크롤 발생** |

### 5.4 위반 판별 체크포인트 (체크리스트 #5)
1. 뷰포트 1920px에서 하단 가로스크롤바 존재 → 위반
2. 뷰포트 1194px에서 가로스크롤바 발생 → 위반
3. 뷰포트 <1194px에서 Content 폭이 1194px 미만으로 더 줄거나 가로스크롤바가 없음 → 위반
4. 뷰포트 >1920px에서 UI가 확대되지 않고 좌측 정렬 + 우측 여백만 발생 → 위반
5. 세로 스크롤 시 Header/Left Area가 함께 스크롤되어 사라짐 → 위반
6. 해상도 변경 간 Left Area 폭이 변함 → 위반
7. 뷰포트 ≤1424px인데 Left Area가 기본 펼침 → 위반
8. Header Area 내부에 스크롤바 존재 → 위반
9. 핵심 액션·필수 정보가 스크롤을 내려야만 보임 → 위반
10. (예외) Data Grid **내부** 스크롤은 위반 아님
