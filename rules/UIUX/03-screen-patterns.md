# 03. Screen Patterns — 9패턴·Grid·마스터디테일·Process·Empty State

> 정본: `docs/pmx-uiux-audit/rules/uiux-standard-rules.md` §Page UI Pattern(p.24~27)·§그리드(p.28~35)·§Master-Detail(p.36~43)·§Process(p.55)·§Empty State(p.57~58).
> 화면 착수 시 **먼저 이 문서에서 패턴을 고르고**, 개발 아키타입은 `.claude/rules/develop/a-archetype/`에서 매칭한다.

## 1. Page UI Pattern 9타입 (p.25)

| 패턴 | 구조 | 판별 포인트 | develop 아키타입 |
| --- | --- | --- | --- |
| Grid Main | 검색바 + (신규/삭제) + 단일 그리드 | 상세 영역 없이 그리드만 | A-01 |
| Single Sub (n:1) | 좌: 그리드 / 우: 단건 `Title:값` 폼 | 우측이 세로 나열 폼 | A-02 |
| Single Sub (n:n) | 좌: 그리드 / 우: 그리드(행추가/행삭제) | 우측도 그리드 | A-02 |
| Tree + Detail | 좌: 트리(▼▶) / 우: 상세 | 좌측 계층 들여쓰기 | A-02 |
| Shuttle | 좌 그리드 ↔ 추가>/<삭제 ↔ 우 그리드 | 이동 버튼 쌍 | — |
| Accordion List | Title+검색+라디오필터 + 펼침/접힘 리스트 | 항목별 ⌄/⌃ 토글 | — |
| Calendar | Title+연도+주간/월간/리스트 토글 + 요일 그리드 | 뷰 전환 토글 | — |
| Process | Title+스텝바+조회/요약+취소/다음 + 하단 그리드 | 상단 스텝퍼, "다음" | — |
| Empty State | Title+새로고침 + 중앙 아이콘/문구/버튼 | 0건 시 중앙정렬 안내 | — |

**업무유형 → 패턴**: 다건 목록만(상세 없음)=Grid Main · 조회+단건 상세=Single Sub(n:1) · 조회+다건(1:N) 상세=Single Sub(n:n) · 계층 탐색+상세=Tree+Detail · 양방향 항목 배정=Shuttle · 접이식 목록(공지·FAQ)=Accordion · 일정=Calendar · 다단계 순차 워크플로=Process · 0건=Empty State.

## 2. Data Page Type — 단건/다건 모드 (p.26)

**단건**: ① View(버튼 신규/수정/삭제, 필드 읽기전용 `Title:값`) → 수정 → ② Edit(버튼 취소/저장, 입력 가능) → 저장 → ①.
**다건**: ③ View(신규/수정/삭제, 텍스트+연관조회 버튼) · ④ Edit(취소/저장 + 행추가/행삭제, 셀 입력) · ⑤ View/Edit 분할(좌·상=View / 우·하=Edit, 저장 시 Edit가 View로 전환되고 좌측 반영).

## 3. 상세 정보 제공 방식 (p.26~27)

| 방식 | 조건 | 배치 |
| --- | --- | --- |
| **In page** | Main/Sub 동시확인 필요성 높음 | 세로/가로 분할, Sub는 하단 또는 우측 |
| **Move page** | Sub 정보량 많음 또는 동시확인 필요성 낮음 | 별도 페이지 이동 |
| **Dialog** | 특정 셀·항목 단위 상세 등록/조회 | 흐름상 선행 필수 = **Modal**, 아니면 **Modeless** |

## 4. Grid Main (View) — p.28~29

- **Overview**: 조회된 다건이 **하나의 목록**에 제공되는 단순 목록 조회형.
- **Flow**: 신규/"수정" 선택 → Edit 모드 전환, 저장 완료 시 **Toast**. Row 선택 → View 모드. Cell 단위 상세는 **Dialog**로 오픈(링크/버튼을 셀 안에 명확히 표시). 삭제는 선택 → **컨펌 Dialog("삭제하시겠습니까?")** → 목록 복귀 → Toast.
- 헤더: 좌측 서브타이틀+즐겨찾기(별), 우측 **업무담당자 배지**(이름+전화번호+ⓘ).
- 조회조건: 필수는 라벨 앞 **빨간 `*`**, 미입력은 Placeholder. 영역 **우측 하단**에 새로고침 아이콘 + 조회 버튼(강조색).
- 목록 상단: 좌측 `서브타이틀 + 총 N건`(N 강조색) `+ Info Text(optional)`, 우측 기능버튼 그룹.

## 5. Analytical View — 집계형 목록 (p.30)

- 합계수치를 포함한 통계형 목록은 **최하단에 "총합" 행을 강조색 배경(주황·적색 계열)** 으로 별도 표시, 값은 우측정렬.
- 기본은 조회용이나 업무요건에 따라 CRUD 포함 가능.

## 6. Detail Dialog (p.31)

- 상세 확인은 Cell 선택 시 **페이지 이동이 아니라 Dialog(모달)** 로 노출.
- 구성: 상단 타이틀 + 우측 상단 X / 본문은 **라벨:값 2컬럼 표** / 하단 우측 **"확인" 버튼 1개만**(취소 없음).

## 7. Single Create / Saved View — 단건 폼 (p.32~33)

- **Create**: 작성 Form 페이지로 이동. 상단 액션바 **우측**에 `취소 → 임시저장 → 저장`, **저장만 강조색**.
- 필드 영역: 라벨은 좌측정렬 + **회색 배경 컬럼**, 값은 우측 입력영역. 이메일=아이디+@+도메인, 전화=국가코드+지역번호+번호 분리, 주소=검색버튼+기본주소(읽기전용)+상세주소, 첨부=드래그앤드롭 영역+안내문구.
- **Saved View**: 저장 후 상단 버튼이 **목록 / 수정 / 삭제**로 전환되고 필드는 **읽기전용 텍스트**(input 제거).
- 저장 완료 Toast는 **화면 중앙 하단**.

## 8. Grid Main (Edit) — p.34~35

- **Overview**: 하나의 그리드 안에서 직접 CRUD.
- **Flow**
  - **행추가(+)**: 행 추가 시 상태컬럼에 **`[추가됨]`**. 다건 선택 업무는 행추가 시 **검색 Dialog** 오픈 → 선택 수만큼 행 생성.
  - **수정**: 셀 직접 입력, 저장값이 바뀌면 **`[변경됨]`**.
  - **행삭제(−)**: 선택 후 삭제 시 **`[삭제됨]`** 표시(**즉시 사라지지 않음**).
  - **초기화**: 변경분 취소하고 원상 복원. **저장**: DB 반영 후 Toast.
- **상태컬럼 위치**: 그리드 좌측 **체크박스 다음 두 번째 컬럼**. 값 = 추가 / 삭제 / 빈칸(변경없음).
- **행 상태 시각 구분**: 추가행 = **연한 초록 배경** / 삭제행 = **연한 적·주황 배경 + 취소선** / 편집중 셀 = **파란 테두리 input**.
- 편집 가능 컬럼과 불가 컬럼은 시각적으로 구분(입력박스 vs 텍스트). 편집불가 컬럼은 헤더에 "(편집 불가능)" 명시 가능하며 중앙정렬 허용.
- 버튼: 그리드 우상단에 **+행추가 / −행삭제**(다운로드·새로고침과 별도 배치), 조회 액션바에 조회/초기화/저장.
- 저장 시 flagCd `C`/`U`/`D` 매핑 — 삭제행 포함 수집(`getGridJsonData`/`getSaveJson`). → `develop/b-feature/b-07`

## 9. 마스터-디테일 / Tree (p.36~43)

| 패턴 | 구성 | 배치 기준 |
| --- | --- | --- |
| **Grid Main + Single Sub (n:1)** | 좌·상 목록 그리드 / 우·하 단건 상세 폼 | 컬럼수 적음 → 좌우, 많음 → 상하 |
| **Grid Main + Grid Sub (n:n)** | 좌·상 목록 / 우·하 다건 서브목록 | 동일 |
| **Tree + Detail** | 좌 뎁스 트리 / 우 유형별 상세(폼·그리드·차트) | 조직·체계형 뎁스 목록 |

### 공통 규칙
- 마스터 **미선택 시 상세 영역은 Empty State**(문서 아이콘 + "데이터를 선택하세요").
- **신규** 버튼 선택 시 상세영역이 **즉시 Edit 모드**로 전환. Row 선택 시 해당 데이터로 전환.
- 저장 완료 시 **Toast("저장되었습니다.")**.
- 마스터 삭제: 체크박스 1개 이상 선택 → 삭제 → **컨펌 Dialog** → 목록 복귀 → Toast.
- 조회영역 우측 끝 버튼 순서: **새로고침 → 조회 → 저장**(저장만 강조색).
- 각 패널 우측 상단에 업무담당자 배지.

### n:n 전용
- 서브 그리드 툴바는 **행추가 / 행삭제 2개만**(신규·복사·다운로드·새로고침 없음).
- 서브 그리드 헤더 첫 컬럼에 전체선택 체크박스.
- **서브 삭제는 컨펌 없이 즉시 행 제거 → 저장 버튼으로 확정.** 마스터 삭제(컨펌 O)와 흐름이 다르다.

### Tree + Detail 전용
- 좌측 트리는 ▼/▶ 확장·축소 + 들여쓰기. 우측은 선택 전 Empty State("데이터를 선택하세요"), 선택 후 유형별 데이터(Grid/Table/Chart/Form 가변).
- 단순 평면 목록에는 쓰지 않는다(그때는 Grid Main).

## 10. Process — 단계형 (p.55)

1. 상단 = 단계 바, 하단 = 선택 단계의 요약/상세 (2단 구성).
2. 단계 전환은 **URL/페이지 이동 없이** 동일 화면 내에서 처리.
3. 상단 단계 선택 → 하단 콘텐츠 즉시 갱신.
4. **첫 단계는 '다음'만 노출**('이전' 미노출).
5. 중간 단계부터 '이전'/'다음' 동시 노출.
6. 순서 미도래 단계는 **비활성(disabled)** 표시.
7. **비활성 단계 클릭 시 화면 이동 없음.**
8. 하단 그리드의 신규/삭제 버튼은 그리드 우측 상단, 상세는 그리드 우측 `Title:` 필드 배치.

## 11. Empty State (p.57~58)

**표시 원칙**: 데이터 없음 / 권한 없음 / 오류로 컨텐츠 표시 불가 시 **완전 공백이나 에러 노출 금지** — 반드시 아이콘 + 안내문구 조합.

| 타입 | 배치 범위 | 구성 | 상황 |
| --- | --- | --- | --- |
| **Page** | 화면 전체 | 상단 타이틀+담당자 배지 **유지** / 중앙 아이콘 + 굵은 헤드라인 + 회색 보조설명 + (선택)아웃라인 버튼 | 접근권한 없음, 페이지 전체 표시불가 |
| **Grid** | 그리드 영역 | **검색영역·컬럼헤더 유지**, 데이터 로우 영역 안에만 아이콘+문구 중앙 배치 | 조회 결과 0건 |
| **with Suggestion** | Title 우측상단 + 본문 | 새로고침 아이콘(**Title 라인 우측 최상단**) + 추천 경로 버튼(**본문 내부**) | 재시도·대안 경로 안내 |

- Page형 세로 구성 순서(중앙정렬): ① 상태 아이콘 → ② 굵은 헤드라인("접근 권한이 없습니다.") → ③ 작은 회색 보조설명 → ④ (선택) 아웃라인 액션 버튼.
- Grid형은 **헤더/프레임까지 감추지 않는다.** Suggestion형 두 버튼의 **위치 교환 금지**.
- 초기 진입 화면은 Empty State로 시작("조회를 실행해주세요" / "데이터를 선택하세요"). 초기 조회조건이 있으면 조회 결과 상태로 호출.

## 12. 모듈 툴바 버튼 순서

- **`신규/행추가 > 삭제/행삭제 > 복사/행복사 > 위로 > 아래로 > 업로드 > 다운로드 > 새로고침`** (p.65 기준). 필요한 기능만 배치하되 순서는 유지.
- 정본 p.36~43(마스터디테일)에는 `신규 > 복사 > 삭제 > 다운로드 > 새로고침` 순서가 나오지만, **p.65(Button 전용 페이지)를 우선한다.**
